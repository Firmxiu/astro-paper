unsigned = unsigned int
有一些jcc是用来比较有符号数的 有些是比较无符号数的
有符号数和无符号数在内存中的表现形式完全一样 区别是取决我们怎么定义他们 一般情况下我们只有在运算和比较有无符号的数时才会定义他们
Jle和Jbe的区别
这两个都是**条件跳转指令**，**唯一的本质区别：判断的是【无符号数】还是【有符号数】的大小**。

| 指令  | 全称                   | 适用类型                | 判断逻辑             | 等价 C 语言   |
| ----- | ---------------------- | ----------------------- | -------------------- | ------------- |
| `JBE` | Jump if Below or Equal | **无符号数** (unsigned) | 小于**或**等于则跳转 | `<=` (无符号) |
| `JLE` | Jump if Less or Equal  | **有符号数** (signed)   | 小于**或**等于则跳转 | `<=` (有符号) |

## 标志位判断不同

CPU 不区分数据是有符号还是无符号，**只看标志位**，两个指令判断的标志位组合不一样：

- **`JBE` (无符号 ≤)**：判断 `CF=1` 或 `ZF=1`
  - `CF`：进位 / 借位标志（无符号数运算专用）
  - `ZF`：零标志
- **`JLE` (有符号 ≤)**：判断 `SF≠OF` 或 `ZF=1`
  - `SF`：符号标志
  - `OF`：溢出标志（有符号数运算专用）
  - `ZF`：零标志

| 比较类型   | 小于 | 小于等于 | 大于 | 大于等于 |
| ---------- | ---- | -------- | ---- | -------- |
| **无符号** | `JB` | `JBE`    | `JA` | `JAE`    |
| **有符号** | `JL` | `JLE`    | `JG` | `JGE`    |

浮点类型
float和double类型
float i = 12.5f;
12.5f在内存中存储形式位41480000h
float和double在存储方式尊测IEEE规范 任何一个浮点数都是由三部分组成的
整数部分/对应进制的余数就是当前位
将浮点型转化为内存存储格式的步骤为

1. 先将这个实数的绝对值化为二进制格式
   8.25转而二进制
   8/2=4 0
   4/2=2 0
   2/2=1 0
   1/2=0 1
2. 小数部分0.25转成二进制
   0.25x2=0.5 0
   0.5x2=1.0 1
3. 最终可以表示为1000.01
   10000 = 1x10^3
   1000.01 = 1x2^3
   小数点向左移动三位指数为3
   > 将这个二进制格数实数的小数点左移或者右移N位 直到小数点移动到第一个有效数字的右边
4. 从小数点右边第一位开始数出23位数字放入第22位到第0位

0-22尾数部分(小数部分) 位数部分是指精确的位数 float类型可以精确到小数点后6位
